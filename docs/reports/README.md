# 작업 보고서

이 디렉터리는 PR만으로 보존하기 어려운 장기 판정이나 실행·복구 증거가 필요한 작업 보고서를 보관한다. 보고서와 생략 사유는 기본 산출물이 아니며, 작성 조건은 `docs/runbook/lean-harness.md`를 따른다.

경로 형식은 다음과 같다.

```text
docs/reports/<작업 ID>/<role>-report.md
```

보고서가 존재하면 최소한 작업, 목적, 결과 또는 증거, 위험 또는 제한을 남긴다. `실행 구분: 실제 운영 실행`인 보고서에만 명시적 승인, 적용 전후 확인, 독립 확인, 복구·rollback, 미실행 항목과 남은 위험을 추가한다.

새 보고서는 `docs/reports/task-report-template.md`를 기준으로 작성한다.
