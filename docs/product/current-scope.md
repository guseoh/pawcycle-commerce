# 현재 제공 기능과 제외 범위

이 문서는 **지금 `main`에 구현돼 있는 사용자·관리자 기능**을 제품 관점에서 한 장으로 정리한 것이다. 기능을 처음 정의한 요구사항 문서(PS-001~005)와 MVP3·MVP4 계약(API-006~012)은 당시 결정의 원본으로 남아 있다. 이 문서는 그 결과로 무엇이 남았는지를 보여 준다.

- 확인 기준: `main` `70af0c3d`, 2026-11-14. Backend Controller와 Frontend 경로를 대조했다.
- "구현됨"은 코드가 있다는 뜻이다. 운영 환경에서 검증됐다는 뜻은 아니다([운영 개요](../architecture/production-operations-overview.md)).

## 고객 기능

| 영역 | 기능 | 비고 |
| --- | --- | --- |
| 계정 | 이메일·비밀번호 로그인(세션), 로그아웃, 배송지 관리 | 소셜 로그인·JWT 없음 |
| 탐색 | 상품 목록·검색·필터(반려동물 종류, 카테고리, 브랜드, facet, 가격), 정렬, 상세(옵션·이미지·상세 섹션), 상품 비교 | 검색은 부분 일치(LIKE) |
| 신뢰 정보 | 리뷰, 상품 문의와 답변 알림, 리뷰 요약 | 리뷰 요약 AI는 기본 꺼짐 |
| 찜·추천 | 찜 목록, 개인화 추천 | 추천 AI는 기본 꺼짐(꺼지면 서버 규칙 순서) |
| 구매 | 장바구니, 쿠폰 적용, Checkout, Toss 결제, 결제 성공·실패 화면, 주문 목록·상세, 빠른 재주문 | |
| 사후 처리 | 결제 후 취소, 반품 요청, 환불 | 반품 승인·입고는 관리자 |
| 멤버십 | 등급 조회, 등급별 혜택 | 결제 완료 시 등급 평가가 반영되고, 관리자가 수동 평가도 할 수 있다 |
| 정기배송 | 펫 등록, 플랜 선택·구독 생성, 일시정지·재개·해지, 다음 회차 건너뛰기·날짜 변경, 주기·플랜 변경, 다음 회차 애드온, 정기결제 수단 등록 | 회차 주문은 자동 생성 |
| 알림 | 앱 내 알림(주문·배송·결제 조치 필요·취소·반품·환불·구독 보류·문의 답변·배송 예정) | 이메일·SMS·푸시 없음 |
| 안내 | FAQ, 공지, 배송 안내, 고객지원 페이지 | 정적 안내 |

## 관리자 기능

| 영역 | 기능 |
| --- | --- |
| 카탈로그 | 브랜드·카테고리·facet·상품·SKU·옵션·이미지·상세 섹션 생성·수정, 리뷰·문의 관리 |
| 주문·결제 | 주문 조회, 결제 대사 실행, 정기결제 재시도 |
| 재고 | 재고 조회·조정 |
| 쿠폰·멤버십 | 쿠폰 생성·발급, 등급 관리·평가 |
| 배송·사후 처리 | 배송 상태 진행, 반품 승인·거절·입고, 환불 처리 |
| 운영 | 처리 대기 건 조회(`/admin/operations`), 감사 로그 |

## 구현되지 않은 것 (확인됨)

아래는 코드에 없음을 확인한 기능이다. 도입 여부는 별도로 결정한다. 보안·운영과 관련된 공백은 [알려진 위험](../architecture/known-risks.md)에도 있다.

| 기능 | 현재 |
| --- | --- |
| 재입고 알림 | 없음. 코드의 `restock`은 반품 입고 시 재고 복원을 뜻한다 |
| 외부 알림 채널(이메일·SMS·카카오) | 없음. 앱 내 알림만 있다 |
| 요청 횟수 제한(rate limit) | 없음 |
| 전문 검색(FULLTEXT·검색 엔진) | 없음 |
| 소셜 로그인, JWT | 없음(ARCH-006에서 JWT 보류) |
| 이벤트 발행·Outbox | 없음. 부가 처리는 트랜잭션 안에서 순서대로 실행한다 |
